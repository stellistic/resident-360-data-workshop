# Facilitator provisioning runbook

This public participant repository intentionally does **not** include the private facilitator provisioning runbook or deployment artifacts.

Participants do not need those materials to complete the workshop. The live workshop facilitator provides any required `metadatadb` connection placeholders during Lab 2 and operates the shared hub workspace separately.

Keeping those details out of this repository avoids publishing tenant coordinates, workspace IDs, private pipeline templates, rosters, or operational notes.
